Autonomous Intermediate Battery Charging System for UAVs

Modified PX4 firmware (C/C++) to enable mid‑mission waypoint diversion to autonomous charging stations.

Overview: Modified PX4 mission manager to allow dynamic waypoint injection based on battery thresholds.

Architecture: PX4 Firmware → MAVLink → QGroundControl → Gazebo SITL.

Firmware Logic: Battery < threshold → override mission waypoint → navigate → simulate charging → resume mission.

Validation: SITL tests with diversion logs, MAVLink inspector, and QGC mission replay.

Challenges: PX4 mission manager restrictions, static battery model.

Solutions: State machine modification + custom battery drain model.
